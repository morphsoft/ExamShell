Nome do exercício  : camel_to_snake
Arquivos esperados : camel_to_snake.c
Funções permitidas : malloc, realloc, write, free
--------------------------------------------------------------------------------
Escreva um programa que recebe uma única string no formato lowerCamelCase
e a converte para o formato snake_case.

Uma string lowerCamelCase é uma string em que cada palavra começa com letra
maiúscula, exceto a primeira.

Uma string snake_case é uma string em que cada palavra está em minúsculas,
separadas por um underscore "_".

Exemplos:
$>./camel_to_snake "hereIsACamelCaseWord"
here_is_a_camel_case_word
$>./camel_to_snake "helloWorld" | cat -e
hello_world$
$>./camel_to_snake | cat -e
$
