Assignment name  : ft_strspn
Expected files   : ft_strspn.c
Allowed functions:
--------------------------------------------------------------------------------
Reproduce exactly the behavior of the function strspn (man strspn).

The function should be prototyped as follows:

size_t	ft_strspn(const char *s, const char *accept);

Examples:

ft_strspn("129th", "0123456789") returns 3.
ft_strspn("abc", "xyz") returns 0.
ft_strspn("abcabc", "abc") returns 6.
