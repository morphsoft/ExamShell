Assignment name  : ft_list_remove_if
Expected files   : ft_list_remove_if.c, ft_list.h
Allowed functions: free
--------------------------------------------------------------------------------

Write a function called ft_list_remove_if that removes from the
passed list any element the data of which is "equal" to the reference data.

It will be declared as follows :

void	ft_list_remove_if(t_list **begin_list, void *data_ref, int (*cmp)());

cmp takes two void* and returns 0 when both parameters are equal.

You have to use the ft_list.h file, which will contain:

$>cat ft_list.h
typedef struct      s_list
{
    struct s_list   *next;
    void            *data;
}                   t_list;
$>

Examples:

In these examples, ["a"] is an element whose data points to the string "a",
and cmp is a function that compares two strings (it returns 0 when they are
equal). The list is shown after the call.

ft_list_remove_if(["a"] -> ["b"] -> ["c"] -> NULL, "b", cmp) gives
["a"] -> ["c"] -> NULL.
ft_list_remove_if(["a"] -> ["b"] -> ["c"] -> NULL, "a", cmp) gives
["b"] -> ["c"] -> NULL.
ft_list_remove_if(["a"] -> ["a"] -> ["a"] -> NULL, "a", cmp) gives NULL.
