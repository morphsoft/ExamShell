Escreva um programa que recebe uma string e exibe a primeira palavra dela, seguida de uma quebra de linha.

Uma palavra é um trecho da string delimitado por espaços/tabs, ou pelo início/fim da string.

Se o número de parâmetros não for 1, ou se a string não tiver nenhuma palavra, exiba apenas uma quebra de linha.

Exemplos

$> ./first_word "FOR PONY" | cat -e FOR$ $> ./first_word " " | cat -e $ $> ./first_word "a" "b" | cat -e $ $> ./first_word " lorem,ipsum " | cat -e lorem,ipsum$
$> ./first_word
